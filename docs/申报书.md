项目名称：moonshop：MoonBit 极简电商演示系统（领域引擎 + 网页商店 + HTTP API + 管理台）

项目方向：MoonBit 领域建模 / Web 全栈应用

moonshop 用纯 MoonBit 从零实现一个电商领域引擎——商品目录、库存、购物车、五段定价流水线、库存预占、带价格快照的订单结账——并以三种形态交付：wasm-gc 驱动的网页商店（中英双语）、Node 上运行的 HTTP API 服务、与商店共享同一份数据的管理台。金额全程以整数分表示、结账先校验后变更、订单快照下单时刻的价格与名称；账号系统内置手写 SHA-256 盐化密码认证与 Admin/Staff/Customer 角色权限。moonbitlang/core 标准库之外零第三方依赖，网页上零业务 JavaScript。

提供完整电商领域模型（Product / Cart / Store / Order / PriceBreakdown），金额全程整数分杜绝浮点误差，结账先校验后变更，订单以下单时刻的价格与双语名称做不可变快照，目录改价不改历史；

提供五段定价流水线：单品批发折扣（3 件起 95 折）→ 订单满减（满 X 减 Y，封顶不透支）→ 优惠券（满额门槛 + 码注册表）→ 会员折扣（百分比钳制 0–50）→ 阶梯运费（满 ¥99 免邮 / 满 ¥49 标准 / 小额附加），每个阶段在 PriceBreakdown 中透明留档并渲染进小票；

提供库存预占与超时释放：store_reserve / store_available / store_sweep（逻辑时钟驱动），普通结账按"可用库存 = 在手 − 有效占货"校验，预占结账原子提交（成功耗占货、失败分文不动）；

提供订单系统：MO 序号自动递增、按单号查询、订单 JSON 导出/导入回环（导入自动顶高单号序列防冲突）；

提供账号与权限系统：手写 SHA-256（FIPS 180-4 标准向量验证）+ 盐化 1000 轮拉伸 + 常量时间比较的密码认证，Admin/Staff/Customer 角色层级，会话令牌按逻辑时钟过期与清扫，改密需验旧密；

提供 wasm-gc 网页商店：中英一键切换（商品名、类目、定价明细、历史小票整体重渲染），目录/库存/订单经 localStorage 持久化（刷新不丢、一键重置），低库存红色预警，自定义商品卡片展示图片（无图用类目 emoji 兜底）与介绍；页面零业务 JavaScript——DOM 桥接仅三个函数，全部业务逻辑是 MoonBit；

提供 Node HTTP API 服务（cmd/server）：商品列表 / 下单 / 订单列表 / 按单号查询 / 注册 / 登录 / 登出 / 当前用户 / 管理员补货等接口，宿主侧仅约 20 行 socket 胶水，每个路由决策与业务规则都是 MoonBit；下单需登录（401）、补货需 Admin（403）；

提供管理台（cmd/admin）：上架新商品（介绍、图片 URL、价格元转分零浮点解析、ID 留空按内容哈希自动生成）、逐品下架（不影响历史订单快照）、逐品补货、订单流水表，与商店共享同一引擎实例与 localStorage 数据，补货后商店刷新即见；

提供商品资料多语言：name_en 英文名贯通目录导入、双语搜索（中英文关键词互查）、订单快照与小票按当前语言重渲染；介绍（desc）与图片（image）字段全链路并可搜索；

提供覆盖 SHA-256 标准向量、密码生命周期、角色门禁、定价各阶段、预占阻塞与清扫、JSON 往返的行为测试共 30 个（全部通过、零警告），开发过程在公开仓库以 23 个有效 commits 进行，每个 commit 对应一个完整功能；

提供 README 完整文档：问题定位、方向与通用性说明、三个完整使用场景、API 一览、网页演示与 HTTP API 快速开始、路线图与原创性声明。

项目性质：原创项目。从空白工程开始开发，非移植项目，未参考或复用任何已有开源项目的实现；JSON 解析/序列化模块复用自同一作者本人的 benchlens 项目（同为 Apache-2.0 许可证，json.mbt 文件头已注明出处），除此之外仅使用 moonbitlang/core 官方标准库，零第三方依赖。
